Common problems
Things that catch people out the first time. All tested on Windows.
Terminal says 'sf is not recognised' after installing the Salesforce CLI
Close VS Code completely and reopen it â€” don't just close the terminal tab, close the whole application. Open a new terminal and try again. If it still fails, do a full Windows restart. The CLI installer updates your system PATH and Windows sometimes needs a full reboot to pick it up.
The browser opened for org auth but nothing happened in VS Code
Check that you clicked Allow on the Salesforce permissions screen in the browser. VS Code waits for that confirmation before proceeding. If you closed the browser window before clicking Allow, run the authorise command again from the Command Palette (Ctrl+Shift+P â†’ SFDX: Authorize an Org).
Claude Code extension installed but Ctrl+Esc doesn't open anything
Try Ctrl+Shift+P and search for "Claude Code" to find the open panel command manually. If nothing appears, reload VS Code â€” go to Ctrl+Shift+P â†’ "Reload Window". If you're still not signed in, the panel will prompt you to log in first.

This can happen if VS Code doesn't have permission to store credentials. Try signing in again â€” it's quick. If it keeps happening, check that you're running VS Code as your normal user (not as Administrator), as credential storage behaves differently in elevated mode.
Deployment failed â€” 'This component is not available for this page type'
